# 🎯 디지털 트윈 대시보드 - 하이브리드 CSV Import/Export 시스템

## 📊 새로운 하이브리드 CSV 시스템 개요

디지털 트윈 대시보드에 **혁신적인 하이브리드 방식** CSV import/export 기능이 추가되었습니다! 이제 Excel에서 성과 데이터를 쉽게 분석할 수 있으며, 데이터 무결성도 완벽하게 유지됩니다.

## 🚀 주요 특징

### 🎯 하이브리드 방식 (권장)
- **플래튼닝**: 성과목록을 각 행으로 분리하여 저장
- **Excel 분석**: 피벗테이블로 성과 분석 가능
- **스마트 복원**: 가져오기 시 원본 구조로 자동 복원
- **성과순번**: 성과의 순서를 나타내는 컬럼 추가

### 📄 레거시 방식 (호환성)
- **기존 호환**: 기존 시스템과 완벽 호환
- **JSON 내장**: 성과목록을 JSON 문자열로 저장
- **컴팩트**: 파일 크기 최적화

## 🔧 사용 방법

### 📤 데이터 내보내기

1. **🎯 스마트 저장** 버튼 클릭 (권장)
   - 하이브리드/레거시 방식 선택 가능
   - JSON/CSV 형식 선택
   - 실시간 미리보기 제공

2. **CSV 저장** 버튼 클릭 (빠른 저장)
   - 레거시 방식으로 즉시 저장

### 📥 데이터 가져오기

1. **📂 파일 불러오기** 버튼 클릭
2. **자동 형식 감지**: 하이브리드/레거시 자동 구분
3. **미리보기**: 가져올 데이터 사전 확인
4. **병합 옵션**: 전체교체/병합/추가 선택

## 🎯 Excel 분석 활용법

### 하이브리드 CSV로 피벗테이블 만들기

1. **데이터 준비**
   ```
   하이브리드 CSV 파일을 Excel에서 열기
   ```

2. **피벗테이블 생성**
   ```
   삽입 → 피벗테이블 → 전체 데이터 범위 선택
   ```

3. **분석 예시**
   - **행**: 사업부, 프로세스
   - **열**: 성과_대분류
   - **값**: 성과_과제기여도 (평균)
   - **필터**: 진행상태, 과제년도

4. **고급 분석**
   - 사업부별 성과 기여도 평균
   - 프로세스별 목표 달성률
   - 월별 프로젝트 진행 현황

## 🔄 데이터 변환 과정

### Export (내보내기)
```javascript
// 하이브리드 방식: 성과목록 플래튼닝
projects.forEach(project => {
  project.성과목록.forEach((performance, index) => {
    csvRows.push([
      project.id,
      project.과제명,
      // ... 기본 정보
      index + 1, // 성과순번
      performance.대분류,
      performance.소분류,
      // ... 성과 정보
    ]);
  });
});
```

### Import (가져오기)
```javascript
// 하이브리드 방식: ID별 그룹핑 후 재조립
const projectGroups = groupBy(csvData, 'id');
const projects = Object.values(projectGroups).map(group => {
  const baseProject = group[0];
  const 성과목록 = group
    .filter(row => row.성과순번 > 0)
    .map(row => ({
      대분류: row.성과_대분류,
      소분류: row.성과_소분류,
      // ... 성과 정보 복원
    }));
  return { ...baseProject, 성과목록 };
});
```

## 🔧 트러블슈팅

### 일반적인 문제

**Q: 하이브리드 CSV에서 성과가 중복되어 보여요**
```
A: 정상입니다. 각 성과가 별도 행으로 표시되어 Excel 분석이 가능합니다.
```

**Q: 레거시 방식으로 가져온 데이터가 깨져 보여요**
```
A: UTF-8 BOM 인코딩을 확인하세요. Excel에서 "데이터 → 텍스트 가져오기" 사용을 권장합니다.
```

**Q: 큰 파일 처리시 느려요**
```
A: 1000개 이상 프로젝트는 JSON 형식을 권장합니다. 또는 데이터를 분할하여 처리하세요.
```
