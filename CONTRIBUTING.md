# Contributing

Thank you for your interest in contributing to this project. Please follow these guidelines.

1. Fork the repository and create a topic branch for your changes.
2. Follow coding style used in the project. For frontend, run `npm run lint`.
3. Add tests for new features or bug fixes where applicable.
4. Open a Pull Request explaining the change; reference any related issue numbers.
5. Ensure CI passes on Windows (GitHub Actions) before requesting review.

For significant changes, open an issue first to discuss the approach.
