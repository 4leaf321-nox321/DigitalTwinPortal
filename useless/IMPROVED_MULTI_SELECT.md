# Knowledge Graph Project - 개선된 다중 노드 선택 기능

## 🔧 문제 해결: Ctrl 키 누른 상태에서 화면 이동 방지

### 🎯 해결된 문제
기존에 Ctrl 키를 누른 상태에서 드래그할 때 화면 이동(패닝)이 발생하여 박스 선택이 어려웠던 문제를 해결했습니다.

### ✨ 개선된 기능

#### 1. 지능적 드래그 모드 전환
- **Ctrl 키 누름**: 네트워크 드래그(패닝) 및 노드 드래그 비활성화
- **Ctrl 키 떼기**: 모든 드래그 기능 다시 활성화
- **박스 선택 중**: 드래그 방지로 정확한 선택 영역 지정 가능

#### 2. 향상된 시각적 피드백
- **Ctrl 키 누른 상태**: 십자 커서 + "드래그하여 여러 노드를 선택하세요" 안내
- **박스 선택 중**: 맥동하는 "마우스를 떼어 선택을 완료하세요" 메시지
- **선택 박스**: 둥근 모서리와 부드러운 애니메이션

#### 3. 정확한 이벤트 처리
- 마우스 이벤트 기본 동작 방지 (`preventDefault()`, `stopPropagation()`)
- 키보드와 마우스 이벤트 통합 관리
- 실시간 Ctrl 키 상태 추적

### 🎮 사용 방법 (개선됨)

#### 박스 선택 방법
1. **Ctrl 키 누르기**: 커서가 십자 모양으로 변경, 드래그 모드 비활성화
2. **드래그 시작**: 시작점에서 마우스 버튼 누르기
3. **드래그**: 원하는 영역까지 드래그 (화면 이동 없이 박스만 그려짐)
4. **선택 완료**: 마우스 버튼 떼기 (영역 내 모든 노드 선택)

#### 개별 선택 방법
- **Ctrl + 클릭**: 개별 노드를 하나씩 선택/해제 (기존 기능 유지)

### 🔧 기술적 개선사항

#### 네트워크 상호작용 옵션 동적 제어
```javascript
// Ctrl 키 누를 때
networkRef.current.setOptions({
  interaction: {
    dragView: false,      // 화면 드래그 비활성화
    dragNodes: false,     // 노드 드래그 비활성화
    zoomView: true,       // 줌은 유지
    selectConnectedEdges: false
  }
});

// Ctrl 키 뗄 때
networkRef.current.setOptions({
  interaction: {
    dragView: true,       // 화면 드래그 활성화
    dragNodes: true,      // 노드 드래그 활성화
    zoomView: true,
    selectConnectedEdges: false
  }
});
```

#### 개선된 이벤트 처리
- 전역 키보드 이벤트 리스너로 Ctrl 키 상태 실시간 추적
- 마우스 이벤트에서 기본 동작 방지로 브라우저 기본 드래그 동작 차단
- 박스 선택 상태에 따른 UI 클래스 동적 적용

- **진행 상태**: 파란색 배경의 맥동하는 "마우스를 떼어 선택을 완료하세요"

### 📱 반응형 지원

- 화면 크기에 따른 안내 메시지 크기 조정

### 🚀 사용 시나리오

#### 시나리오 1: 정확한 박스 선택
1. Ctrl 키를 누르면 커서가 십자 모양으로 변경
2. 드래그 시 화면이 움직이지 않고 파란색 박스만 그려짐
3. 원하는 영역의 모든 노드를 정확히 선택 가능

#### 시나리오 2: 혼합 선택
1. Ctrl + 클릭으로 개별 노드 몇 개 선택
2. Ctrl + 드래그로 추가 영역 선택
3. 선택된 모든 노드를 Delete 키로 한번에 삭제

### 💡 팁
- **정확한 선택**: Ctrl 키를 누른 후 천천히 드래그하면 원하는 노드들만 정확히 선택할 수 있습니다
- **빠른 해제**: ESC 키로 언제든 선택을 초기화할 수 있습니다
- **시각적 확인**: 선택 과정에서 나타나는 안내 메시지를 참고하세요
