# Knowledge Graph Project - 다중 노드 선택 기능

## 🎯 새로 추가된 기능: 다중 노드 선택

### ✨ 기능 개요
여러 노드를 한번에 선택하고 삭제할 수 있는 기능이 추가되었습니다.

### 🎮 사용 방법

#### 1. 다중 선택
- **Ctrl + 클릭**: 여러 노드를 하나씩 선택/해제
- **Ctrl + 드래그**: 박스 선택으로 영역 안의 모든 노드 선택

#### 2. 노드 삭제
- **Delete 키**: 선택된 노드(들) 삭제
- **선택 삭제 버튼**: 2개 이상 선택 시 나타나는 🗑️ 버튼 클릭

#### 3. 선택 해제
- **ESC 키**: 모든 선택 해제
- **빈 공간 클릭**: 모든 선택 해제

### 🎨 시각적 피드백

#### 선택된 노드 표시
- 빨간색 굵은 테두리 (4px)
- 빨간색 그림자 효과

#### 다중 선택 상태 표시
- 우상단에 녹색 상태 표시: "N개 노드 선택됨"
- 삭제 버튼 제공

#### 박스 선택 시각화
- 파란색 점선 테두리
- 반투명 파란색 배경

### 💡 사용법 힌트
화면 우하단에 항상 표시되는 힌트:
- `Ctrl + 클릭으로 여러 노드 선택`
- `Ctrl + 드래그로 박스 선택`

### 🔧 기술적 구현

#### 파일 구조
```
src/components/KnowledgeGraph/
├── KnowledgeGraph.jsx (메인 컴포넌트 - 536줄로 리팩토링됨)
├── hooks/
│   ├── useMultiSelection.js (다중 선택 로직)
│   ├── useBoxSelection.js (박스 선택 로직)
│   └── useKnowledgeGraphEvents.js (키보드 이벤트 - 다중 선택 지원)
└── KnowledgeGraph.css (다중 선택 스타일 추가)
```

#### 주요 특징
- **성능 최적화**: useRef로 이벤트 리스너에서 최신 상태 참조
- **반응형 디자인**: 모바일 환경 지원
- **리팩토링**: 700줄 제한에 맞춰 코드 분리
- **타입 안전성**: TypeScript 준비된 구조

### 🚀 사용 예시

1. **여러 노드 선택하기**
   - Ctrl 키를 누른 상태에서 노드들 클릭
   - 또는 Ctrl + 드래그로 영역 선택

2. **선택된 노드들 삭제하기**
   - Delete 키 누르기
   - 또는 나타나는 🗑️ 버튼 클릭

3. **확인 대화상자**
   - 1개: "노드 '이름'을(를) 삭제하시겠습니까?"
   - 2-3개: "노드 '이름1', '이름2'을(를) 삭제하시겠습니까?"
   - 4개 이상: "선택된 N개의 노드('이름1', '이름2' 등)를 삭제하시겠습니까?"
