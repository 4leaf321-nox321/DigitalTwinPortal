# 디지털 트윈 대시보드 기능 가이드

## 📊 대시보드 기능 개요

디지털 트윈 대시보드는 과제 진행 현황을 실시간으로 모니터링하고 성과 지표를 가시화하는 통합 대시보드입니다.

### 🎯 주요 기능

#### 1. 과제 현황 요약 (ProjectSummary)
- **전체 과제 수**: 등록된 총 과제 개수
- **완료율**: 완료된 과제의 비율 (진행률 표시)
- **정상 진행율**: 완료 + 정상진행 상태 과제의 비율 (진행률 표시)
- **PoC 과제**: Proof of Concept 과제 개수
- **중점 과제**: 우선순위 과제 개수

#### 2. 진행 상태별 현황 (ProgressOverview)
- 각 진행 상태별 과제 개수와 비율
- 진행률 바와 퍼센티지로 시각화
- 색상 코딩으로 상태 구분

#### 3. 사업부별 진행 현황 (DivisionStatusGrid)
- 사업부별 과제 분포
- 각 사업부의 주요 진행 상태 4개 표시
- 사업부별 색상 테마 적용
- 호버 효과로 인터랙티브 표시

#### 4. 진행 상태 분포 (StatusChart)
- 파이 차트로 전체 상태 분포 시각화
- 중앙에 총 과제 수 표시
- 범례에서 개수와 퍼센티지 동시 표시

#### 5. 월별 진행률 추이 (ProgressTrendChart)
- 1-12월 각 월별 진행률 추이 차트
- 진행률에 따른 색상 구분:
  - 80% 이상: 파란색 (우수)
  - 60-79%: 노란색 (양호)
  - 30-59%: 빨간색 (지연)
  - 30% 미만: 회색 (위험)
- 애니메이션 효과로 월별 순차 표시

#### 6. 성과 지표 현황 (PerformanceMetrics)
- **총 성과 지표**: 등록된 성과 지표 개수
- **달성률**: 실적수준이 입력된 성과의 비율
- **평균 기여도**: 과제 기여도의 평균값
- **성과 영역**: 대분류 카테고리 수
- 성과 분류별 상위 4개 카테고리 상세 표시

#### 7. 액션 아이템 현황 (ActionItemsStatus)
- **총 액션 아이템**: 등록된 액션 아이템 개수
- **완료된 아이템**: 완료 표시된 아이템 개수
- **완료율**: 전체 액션 아이템 완료 비율
- **관련 과제**: 액션 아이템이 있는 과제 수
- 과제별 액션 아이템 완료 현황 (상위 4개)

### 📱 반응형 디자인

#### 브레이크포인트
- **1600px 이하**: 3열 → 2열 그리드
- **1400px 이하**: 2열 → 1열 차트 그리드
- **1200px 이하**: 2열 → 1열 하단 그리드
- **모바일**: 전체 1열 스택 레이아웃

### 🔄 데이터 업데이트

대시보드는 다음 상황에서 자동으로 업데이트됩니다:
- 새 과제 추가
- 기존 과제 수정/삭제
- 진행 상태 변경
- 성과 지표 추가/수정
- 액션 아이템 추가/완료 처리

### 💡 사용 팁

1. **빈 데이터 상태**: 데이터가 없을 때 적절한 안내 메시지 표시
2. **툴팁**: 차트 요소에 마우스 호버 시 상세 정보 표시
3. **색상 일관성**: 전체 애플리케이션과 동일한 색상 체계 사용
4. **성능 최적화**: useMemo를 사용한 데이터 계산 최적화

### 🛠️ 기술 스택

- **React**: 컴포넌트 기반 UI
- **Styled Components**: CSS-in-JS 스타일링
- **Framer Motion**: 애니메이션 라이브러리
- **React Hooks**: useState, useMemo를 통한 상태 관리

## 📁 파일 구조

```
components/Dashboard/
├── DashboardView.jsx           # 메인 대시보드 컨테이너
├── ProjectSummary.jsx          # 과제 현황 요약
├── ProgressOverview.jsx       # 진행 상태별 현황
├── DivisionStatusGrid.jsx     # 사업부별 진행 현황
├── StatusChart.jsx            # 진행 상태 분포 차트
├── ProgressTrendChart.jsx     # 월별 진행률 추이
├── PerformanceMetrics.jsx     # 성과 지표 현황
└── ActionItemsStatus.jsx      # 액션 아이템 현황
```

## 🚀 향후 개선 계획

1. **실시간 데이터 연동**: WebSocket을 통한 실시간 업데이트
2. **필터링 기능**: 기간, 사업부, 상태별 필터
3. **드릴다운**: 차트 클릭 시 상세 데이터 보기
4. **엑셀 내보내기**: 대시보드 데이터 엑셀 다운로드
5. **알림 시스템**: 임계값 초과 시 알림 기능
